# User Manual

## Client Experience
The client timer interface displays remaining time, current cost, and workstation details.

## What to Expect
- Countdown timers and warning alerts at key thresholds
- Automatic lock or end-of-session handling when time expires
- Reconnection to the server after temporary network interruptions

## Troubleshooting
- If the timer stops updating, confirm the client can reach the server over the LAN.
- Restart the client application if the connection is interrupted.
- Contact the administrator for session or balance issues.
