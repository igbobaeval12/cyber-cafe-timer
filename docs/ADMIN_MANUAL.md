# Administrator Manual

## Overview
Use the admin dashboard to monitor all connected PCs, start or stop sessions, and review revenue.

## Core Tasks
- Review workstation status and connection health
- Start or stop sessions for a selected PC
- Adjust pricing plans and review receipts
- Export session history and monitor activity

## Security Notes
- Protect the admin account with a strong password.
- Review audit logs for sensitive events.
- Restrict physical access to the server machine.
